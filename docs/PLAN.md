# WinterTower — стек и план работ

## 1. Выбор стека

### Решение: **Three.js (vanilla) + Vite + TypeScript**

Почему не альтернативы:

| Вариант | Вердикт |
|---|---|
| **Three.js vanilla + Vite** | ✅ **Берём.** Ходьба/прыжок/лестницы решаются готовым `Octree` из `three/examples/jsm/math/Octree` — это ~120 строк на весь контроллер. Никаких абстракций между тобой и картинкой. Правки тумана/цвета — мгновенно, hot reload. |
| React Three Fiber + @react-three/rapier | Мощно, но добавляет React, реконсилятор и полноценный физдвижок ради задачи, где нужен один капсульный коллайдер. Слой абстракции мешает крутить атмосферу. Отложить: если проект вырастет в игру с UI и инвентарём — мигрировать несложно. |
| Godot 4 | Настоящий движок, но: свой редактор, свой язык, свой пайплайн импорта, билды. Дольше до первого «я хожу в тумане». |
| Unreal / Unity | Оверкилл. Дни на настройку до первого кадра. |

Node 22.18 и npm 11.1 уже стоят — стек заводится одной командой.

### Зависимости (минимум, ничего лишнего)

```
three                    — рендер
vite                     — dev-сервер + сборка
typescript               — типы (опционально, но дешевле ловить ошибки)
postprocessing (pmndrs)  — bloom для фонарей, вигнетка, зерно, цветокор
lil-gui                  — панель с ползунками тумана/света. Критично для подбора атмосферы
stats.js                 — FPS
```

Всё. Физдвижок — **нет** (Octree хватает). Загрузчики моделей — **нет** (геометрия процедурная). **База данных — не нужна**: сохранять нечего, состояние мира описывается кодом. Если позже понадобится сохранять позицию игрока — `localStorage`, одна строка.

### Звук
Web Audio API напрямую: 1 лупированный трек lo-fi ambient + 1 луп ветра (громкость модулируется шумом) + PositionalAudio на шаги. Библиотека не нужна, `THREE.Audio` уже в three.

## 2. Ассеты: что качать, что делать самим

**Скачать нужно только текстуры и один HDRI.** Всё остальное — код.

### Текстуры (все CC0, ничего не нарушаем)
- **ambientCG.com** — идёт первым, там точно есть всё нужное, скачивается в 1 клик, 2K JPG:
  - `Concrete0xx` — стены зданий (искать выцветший, панельный)
  - `Snow0xx` — снежные наносы
  - `Asphalt0xx` / `Gravel0xx` — дорожка
  - `MetalPlates0xx`, `Rust0xx` — короба, лестница, мачты
- **polyhaven.com/textures** — альтернатива, качество выше, тоже CC0
- **polyhaven.com/hdris** — один пасмурный HDRI (`kloofendal_overcast`, `overcast_soil_puresky` или любой `overcast`) — только как источник ambient-освещения, само небо будет закрыто туманом

Формат: 2K, нужны карты `Color`, `NormalGL`, `Roughness`. `AO`/`Displacement` — не обязательны на старте.
Класть в `public/textures/<имя>/`.

### Готовые модели — по желанию, не обязательно
Если захочешь ускорить детализацию, ищи **только CC0**:
- **poly.pizza**, **sketchfab.com** (фильтр License → CC0), **quaternius.com**
- Что искать: `radio mast`, `antenna tower`, `observatory dome`, `hvac unit`, `industrial door`, `handrail`
- Формат отдавать мне: `.glb`, класть в `public/models/`

Но повторю вывод из разбора: **лестницу, здания, купол и мачты быстрее написать кодом**, чем найти подходящие. Экономия — не в поиске ассетов, а в том, что не нужно их искать.

### Люди — были и сняты
Скачаны в сессии 17, поставлены в мир в 18, сняты в 19: курс сменился на историю
ЗАБРОШЕННОЙ станции. Модели (CC0 Quaternius) и весь разбор — `models-unused/people/`,
вне `public/`, то есть вне сборки. Возвращать их — только если история снова
станет про обитаемую станцию.

## 3. Фазы

Каждая фаза = отдельная сессия, заканчивается запускаемой сборкой.

### Фаза 1 — «Я стою в тумане» (P0 + P3)
Скелет проекта, пустая заснеженная плоскость, FogExp2, hemisphere-свет, ACES-тонмаппинг, холодный грейдинг, контроллер от первого лица (WASD, мышь, прыжок, приседание, коллизия по Octree), lil-gui с ползунками тумана/экспозиции/цвета.
**Критерий готовности:** хожу по белому ничто, и это уже ощущается холодно.

### Фаза 2 — Блокинг (P2)
Серые боксы: рельеф гребня, дорожка, два здания, купол, лестница, мачты. Всё в масштабе, всё проходимо, по лестнице можно подняться.
**Критерий:** встаю в точку камеры с референса — композиция совпадает по силуэтам.

### Фаза 3 — Свет и атмосфера (P0 + P1)
Фонари с ореолами, свет из окон, bloom, вигнетка, зерно, снег двумя слоями частиц, ветер + lo-fi трек, звук шагов по разным поверхностям.
**Критерий:** скриншот из движка рядом с референсом читается как «то же место».

### Фаза 3.5 — Компоновка ✅ сделано в сессии 5

Силуэты и гамма сошлись, а расстановка — нет. Класть текстуры на неправильно
стоящие объекты рано: любая правка компоновки заставит переделывать материалы.

**Что было не так (замерено, не на глаз) и чем закрыто:**

| Факт | Числа | Закрыто |
|---|---|---|
| Дорожка проходит НАСКВОЗЬ через центральный корпус | точки `(-2,-54)` и `(-8,-62)` лежат внутри пятна `x -8…15, z -50…-68` | ось дорожки в `layout.ts`, коридор проверяется `checkLayout()` |
| Решётчатая мачта стоит ВНУТРИ центрального корпуса | мачта `(14,-64)`, то же пятно | мачта на `(16,-90)`, позади и правее корпуса |
| Центральный корпус не на плече купола, а на самом гребне | земля под корпусом `-3.8` м, под куполом `+9.7` м, между ними 37.8 м | корпус на полке рядом с куполом, земля 14.9…17.5 |
| `ROOFS` в `props.ts` дублирует `WING` из `buildings.ts` | одни и те же три коробки заданы дважды; сдвинешь корпус — короба и антенны останутся на старом месте | и то и другое читает `WING` из `layout.ts` |
| Купол висел над землёй | цоколь обрывался на 6.8 м выше грунта: `maxDepth` 4.5 при перепаде 11 м | полка `SHELF_*` в `terrain.ts`, перепад 2.9 м |
| Перила отгораживали верх лестницы | пешком до марша дойти нельзя, автопроход вставал на `(0,-51)` | проём 5.5 м вокруг верха лестницы |

**Как должно быть (порядок по референсу, если идти от игрока вдаль):**

1. смотровая площадка (игрок) → 2. служебный корпус справа вдоль дорожки →
3. дорожка свободна до самого верха лестницы → 4. лестница уходит вниз-влево по борту →
5. НАВЕРХУ, на плече: центральный корпус с лентой окон **рядом с куполом** →
6. купол обсерватории → 7. решётчатая мачта позади и правее корпуса, отдельно стоящая.

Ключевое: **дорожка — коридор, на нём не стоит ничего.** Здания живут сбоку от неё.

**Как сделано:**

1. `world/layout.ts` — таблица пятен, ось дорожки, концы лестницы, мачты.
   Единственный источник правды; `buildings.ts`, `props.ts`, `stairs.ts` читают её.
2. `checkLayout()` — пересечения пятен, коридор дорожки, мачты вне пятен и не на
   отвесе, перепад земли под пятном. Гоняется при каждой сборке мира, доступна
   как `wt.world.check()`; `wt.world.report()` печатает высоты и дистанции.
3. Плечо обсерватории: высота 18 → 24, четыре радиуса вместо одного (иначе вулкан),
   плюс полка `SHELF_*`, срезающая макушку в горизонталь под здания.
4. Мачта на `(16,-90)`, тонкие мачты — на пологой седловине, все вне пятен.
5. Дорожка от подножия марша до верха лестницы `(-1,-58)`, ничего на ней не стоит.
6. Верх лестницы переехал с `(-12,-66)` на `(-1,-58)`: старый был на 100 px левее
   референсного и вне поля зрения дорожки.

**Критерий готовности** (выполнен): из точки спавна читается тот же порядок объектов,
что на референсе; по дорожке можно дойти от площадки до верха лестницы и спуститься
(автопроход, 14 точек, 18 м спуска); проверка зелёная.

**Инструмент:** вид сверху рендером НЕ читается — в сцене нет теней, и с высоты всё
сливается в ровную заливку (проверено в сессии 4). Схема плана рисуется 2D-канвасом
прямо по константам `layout.ts` — `world/plan.ts`, клавиша `L`.

**Чего фаза НЕ закрыла:** станция растянута по глубине против §1 `REFERENCE.md`
(купол 98 м при мишени 50–80). Подъём плеча это не лечит — упирается в крутизну
борта полки. Лечится сжатием профиля `CREST` по Z; см. «Открытые проблемы» в журнале.

### Фаза 3.8 — Сжатие по глубине ✅ сделано в сессии 9

Мир был вдвое «глубже» референса: купол в 98 м при слое 50–80, дальняя скала
в 82 м, туман съедал её на 64%. Сжат к глазу двухзонной картой — ближнее поле
только по Z (0.62), дальнее подобием (0.70). Кадр при этом не сдвинулся ни
на пиксель (`SCALE.md` §2), сдвинулся только туман. Подробности и грабли —
журнал, сессия 9.

### Фаза 4 — Материалы (P4)
PBR-текстуры на всё, мокрый бетон, лужи, снег на горизонтальных гранях, ржавчина, потёки.

**Начинать с двух чисел, а не с текстур.** Замер сессии 9: скала читается как
0.44 от яркости тумана вблизи и 0.79 вдали при мишени 0.66–0.75. При плотности
тумана 0.012 одной подходящей яркости камня не существует вовсе. Нужно поднять
собственную яркость камня до ~0.66 И опустить плотность тумана до ~0.0098 —
после этого класть карты, иначе они лягут на неверную гамму.

### Фаза 5 — Детали (P5 + P6)
Перила, вентиляция, кабели, антенны, двери, таблички. Один заходимый интерьер с тёплым светом и приглушённым снаружи звуком.

### Фаза 6 — Полировка
Оптимизация (инстансинг, LOD, frustum culling), плавность движения, головной боб, инерция, звук ветра громче на открытых местах.

## 4. Структура проекта

```
WinterTower/
├─ docs/
│  ├─ REFERENCE.md      — разбор картинки, палитра, чек-лист
│  └─ PLAN.md           — этот файл
├─ reference/           — скриншоты-референсы + скрины из движка для сравнения
├─ public/
│  ├─ textures/
│  ├─ audio/
│  └─ models/           — если появятся .glb
├─ src/
│  ├─ main.ts           — точка входа, цикл рендера
│  ├─ atmosphere.ts     — туман, свет, постпроцессинг, палитра  ← сердце проекта
│  ├─ player.ts         — контроллер от первого лица + коллизии
│  ├─ audio.ts          — ветер, эмбиент, шаги
│  └─ world/
│     ├─ terrain.ts     — скала, гребень, дорожка
│     ├─ buildings.ts   — здания, купол
│     ├─ stairs.ts      — лестница, перила
│     ├─ props.ts       — мачты, фонари, вентиляция
│     └─ snow.ts        — частицы
└─ index.html
```

Всё «настроечное» (плотность тумана, цвета, интенсивности) — в одном объекте `PALETTE`/`SETTINGS` в `atmosphere.ts`, чтобы крутить атмосферу в одном месте, а не по всему коду.

## 5. Управление

`WASD` — движение, мышь — обзор, `Space` — прыжок, `Shift` — бег, `Esc` — курсор,
`G` — панель настроек атмосферы, `P` — скриншот (падает в загрузки браузера, оттуда переносим в `reference/shots/`).
