# WinterTower — разбор референса

> Единственный источник правды по внешнему виду. Любое решение по сцене сверяем с этим файлом.
> Сам скрин положить в `reference/ref_01.png` (см. `reference/README.md`).

---

## 1. Что на кадре

Высокогорная метеo/астро-станция на скальном гребне. Туман, сумерки, мокрый снег, ветер.
Ощущение: холодно, безлюдно, но где-то внутри горит тёплый свет — там люди.

### Слои по глубине

| Слой | Содержимое | Дистанция |
|---|---|---|
| 0. Foreground | бетонная дорожка, лужи с отражением фонарей, снежные наносы, перила | 0–15 м |
| 1. Правый борт | длинное одноэтажное служебное здание: панельные стены, прямоугольные окна, двери, настенные фонари, короба вентиляции и антенны на крыше | 5–40 м |
| 2. Центр | длинная металлическая лестница вверх по гребню, площадки, ограждения | 15–50 м |
| 3. Левый борт | тёмная мокрая скала с пятнами снега, обрыв вниз | 10–60 м |
| 4. Средний план | купол обсерватории (цилиндр + полусфера со щелью), пристройка с освещёнными окнами | 50–80 м |
| 5. Дальний план | решётчатая мачта-антенна + 5–7 тонких мачт, силуэтом | 70–110 м |
| 6. Атмосфера | стена тумана, снежинки (мелкие вдали, крупные размытые у камеры) | везде |

### Камера в кадре
Высота ~8–10 м над дорожкой (стоим на верхней площадке), взгляд вниз вдоль прохода,
FOV ≈ 60–65°, лёгкий наклон вниз ~10°. Это хорошая стартовая точка спавна игрока.

## 2. Палитра

### 2.1. Что реально стоит в пикселях референса

Снято усреднением по участкам кадра (фаза 3). **Первая, «на глаз» снятая палитра
врала:** глаз читал кадр как серо-голубой, а вебкамера дала жёсткий синий увод —
красного в кадре вдвое меньше синего ВЕЗДЕ, включая снег и бетон.
Насыщенность кадра 0.49, а не 0.15, как у нас было до фазы 3.

```
Небо / туман верх   #7ed0f6   ← самое светлое место кадра
Туман слева         #6ebde4
Туман у горизонта   #75c6ec
Купол в тумане      #71c1e7
Стена корпуса       #579dc0
Скала мокрая        #4b8aad
Снег на плато       #3e738f   ← ТЕМНЕЕ скалы, он мокрый и затоптанный
Дорожка мокрая      #5d7281   ← единственное место, где синева уходит в серый
```

### 2.2. Ключевые отношения (важнее абсолютных чисел)

Абсолютные значения референса догонять нельзя: синий там 246 из 255, вебкамера его
почти срезала. Попытка попасть в них точно даёт неоновый плакат (см. журнал, сессия 4).
Сверяться надо по яркости относительно тумана — это переживает любую экспозицию:

| Что | Доля от яркости тумана |
|---|---|
| Стена корпуса | 0.74 |
| Скала (на ЛЮБОЙ глубине, от ближней до дальней) | 0.66–0.75 |
| Снег на плато | 0.54 |

**Главное из этой таблицы:** светится воздух, а не станция. Всё твёрдое темнее тумана,
и черноты в кадре нет вовсе — самое тёмное место всё ещё светлее половины тумана.

### 2.3. Что подавать движку

Не то же самое, что в 2.1: ACES съедает верх диапазона, поэтому на вход идёт светлее
и синее, чем должно получиться на экране. Актуальные числа — в `PALETTE` (`src/atmosphere.ts`),
там же комментарии, почему каждое такое.

**Ключевое правило:** вся сцена — холодный сине-серый низкоконтрастный диапазон,
и ровно 3–4 тёплых оранжевых пятна. Контраст температуры, а не яркости.
Как только появится второй тёплый источник вне списка — атмосфера ломается.

> **С фазы 12 станция БРОШЕНА, и правило от этого не изменилось — изменился
> список.** Пятен по-прежнему 3–4, но это не жилые окна: печь в дежурке, которую
> кто-то растопил несколько часов назад, фонарь, оставленный им у порога,
> проём открытой двери и красный габаритный огонь на мачте (аварийное питание).
> Всё остальное погашено: лента окон операторской, фасадные фонари, лампы
> в комнатах и в куполе. Комнаты держит слабый ХОЛОДНЫЙ свет из окон (`dusk`
> в `furnish.ts`) — без него интерьер читается не заброшенным, а чёрным.
> Сам референс при этом остаётся эталоном по гамме, глубине и силуэтам:
> расходимся с ним только там, где на картинке горит жизнь.

## 3. Свет

- Прямого солнца нет. Основной свет — **небо**: hemisphere/ambient, сверху `#b6cedd`, снизу отражение снега `#8fa6b4`.
- Плотный туман съедает контраст: на 60 м объект почти сливается с фоном. Тени мягкие, почти отсутствуют.
- Тёплые источники: 2–3 настенных фонаря справа + свечение из окон. Каждый даёт ореол в тумане (halo) и отражение в мокром бетоне.
- Общая экспозиция низкая, сумерки. Ночь — нет, синий час — да.

## 4. Приоритеты: что реально создаёт атмосферу

Порядок работ именно такой. Не наоборот.

| # | Блок | Вклад в «похожесть» | Трудозатраты |
|---|---|---|---|
| **P0** | Туман (FogExp2) + тонмаппинг + цветокор в холод + экспозиция | **~50 %** | часы |
| **P1** | Снег частицами (два слоя: дальний мелкий + ближний крупный размытый) + ветер в звуке + lo-fi ambient трек | **~20 %** | часы |
| **P2** | Блокинг силуэтов серыми боксами: скала, лестница, 2 здания, купол, мачты | ~10 % | день |
| **P3** | Контроллер от первого лица: ходьба, прыжок, лестницы, коллизии | — (это «играбельность», не «атмосфера») | день |
| **P4** | PBR-материалы: бетон, снег, мокрый асфальт, ржавый металл | ~10 % | день |
| **P5** | Детали: перила, фонари, вентиляция, кабели, двери, лужи с отражением | ~7 % | 2 дня |
| **P6** | Один заходимый интерьер с тёплым светом | ~3 % | день |

**Главный вывод анализа:** похожесть даёт не геометрия, а туман + палитра + звук.
Геометрия здесь примитивная — коробки, цилиндры, полусфера, лестница из повторяющегося блока.
Поэтому «искать ассеты» почти не нужно: 90 % сцены собирается кодом из примитивов, скачать надо только **текстуры**.

## 5. Разбор объектов на примитивы

| Объект | Как делать |
|---|---|
| Скала/гребень | плоскость с шумовым heightmap (сгенерить в коде) + вертексная маска снега по углу наклона |
| Дорожка | вытянутый box, материал «мокрый бетон» (roughness map + лужи через roughness = 0.1 пятнами) |
| Служебное здание | box + отдельные плоскости-окна с emissive + рамка из тонких боксов. **CSG не нужен** — окно накладываем сверху, а не вырезаем |
| Лестница | один блок ступени, инстансинг × N вдоль сплайна + перила из цилиндров |
| Купол обсерватории | цилиндр + полусфера, щель — тёмный box поверх |
| Мачты | тонкие цилиндры; решётчатая мачта — 4 стойки + крестовины, инстансинг |
| Вентиляция/короба | боксы разного размера на крыше |
| Перила | 2 горизонтальных цилиндра + стойки через 1.5 м, инстансинг |
| Фонарь | маленький box + PointLight + sprite-ореол (billboard с радиальным градиентом) |

## 6. Чек-лист «похоже / не похоже»

Сверяться скриншотом-в-скриншот на каждой итерации:

- [ ] Дальний план полностью растворяется в тумане, горизонта не видно
- [ ] На кадре ровно 3–4 тёплых пятна, всё остальное сине-серое
- [ ] У фонарей есть видимый ореол в тумане
- [ ] Снег летит с боковым сносом (ветер), не строго вниз
- [ ] Мокрый бетон бликует под фонарями
- [ ] Снег лежит только на горизонтальных поверхностях и наветренных гранях
- [ ] Контраст низкий: черноты нет вовсе, самое тёмное — около половины яркости тумана
- [ ] Всё твёрдое ТЕМНЕЕ тумана (стена 0.74, скала 0.66, снег 0.54 — см. 2.2)
- [ ] Слышен ветер, он меняется по громкости; поверх — тихий lo-fi эмбиент
