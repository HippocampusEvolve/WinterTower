# Winter Tower

Ходибельный 3D-мир от первого лица: высокогорная станция на скальном гребне,
туман, снег, синий час. Цель не игра, а атмосфера - воспроизвести настроение
референсного кадра и дать по нему походить.

Играть: **https://find-the-end.fun/wintertower/**

Мир 02 витрины [find-the-end.fun](https://find-the-end.fun) - небольших
браузерных миров, в каждом из которых спрятан свой конец.

## Стек

Three.js + Vite + TypeScript. Физика - Octree из three (капсула, лестницы,
прыжок). Постпроцессинг - pmndrs/postprocessing.

Моделей нет совсем: вся геометрия - станция, лестницы, гребень, интерьеры -
собирается кодом. Из ассетов только PBR-текстуры.

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```

Вспомогательное: `npm run measure` считает средние по текстурам, `npm run room`
проверяет раскладку помещений, `npm run octree` разбирает дерево коллизий -
во что оно обходится и то же ли получается при сборке по частям.

## Что где

| | |
|---|---|
| `src/world/` | геометрия мира: рельеф, станция, лестницы, интерьеры, материалы |
| `src/hands/` | инструменты от первого лица и их анимация |
| `src/` | игрок, взгляд, атмосфера, снег, ветер, заставка загрузки |
| `public/textures/` | PBR-карты, webp |
| `docs/` | разбор референса, план работ, масштабы |
| `tools/` | служебные скрипты замеров |

Размер карты написан в её имени (`normal_1k.webp`, `rough_512.webp`): на
раздаче текстуры кэшируются на год, поэтому меняешь содержимое - меняй имя.
